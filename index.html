Projects

Golden Ballerina

Golden Ballerina is a game made by my partner and I for the Very Serious Game Jam on itch.io.

It is a precision platformer where you play as a ballerina who can spin the world! We are currently slowly working on a full version of this game.

Starsurfer - Prototype

Starsurfer made last year as a one-month prototype for an endless runner inspired by the Alto series.

The game can be played right now on this website (Desktop Only!), since it is very small!

Controls:
ESC to Pause
Space/LMB to Jump
Hold the Jump action to start backflipping!

Unfortunately, due to a lack of time because of academic duties and
the overwhelming task of making lots of art, the project stayed as a prototype.

ProjectTango - Demo

ProjectTango (name still undecided to this day) is a roguelike treasure hunting game
where you play as Princess Squallita, descending down the dungeons of her Mother
to find her and mend their relationship.

The game takes most of its inspiration and game mechanics from the game Decked Out 2 on the Hermitcraft S9 server.

This project was set aside for a while due to having to focus on college work
and making Golden Ballerina in a very short period of time. I do plan on going back to this!

Modding Projects

The programming done for these mods was done in C#, with the MonoGame engine or a version of it.

Mariana's Odyssey

Mariana's Odyssey is a 6-chapter campaign mod for Celeste
about a girl travelling through the desert to return her beloved from the dead.
It was made for the Celeste Campaign Contest, which it won first place in.

It went beyond from just a custom map by introducing
custom-coded mechanics, secrets, and bosses.

You can find the code for them in this GitHub repository!

Forces of Nature and etc. (Thinf)

Forces of Nature was an old Terraria mod made back in 2020.
It served as my introduction to programming.

It has not been updated for the 1.4 version of tModLoader and is only playable in 1.3.
You can find code in this GitHub repository!
